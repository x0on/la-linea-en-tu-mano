# La Línea en tu mano · Demo

Prototipo de avisos de alumbrado y baches para La Línea de la Concepción.
GECOR está simulado y los datos se guardan en el navegador.

## Publicar

Subir el contenido a un repositorio GitHub en la rama main, incluyendo .github.
En Settings → Pages, elegir GitHub Actions como origen. Ejecutar el workflow
Publish demo y abrir la URL HTTPS que aparece al terminar. La disponibilidad
de Pages para repositorios privados depende del plan y la configuración.

## Demostración en iPhone

Abrir el enlace en Safari. Desde Compartir se puede añadir a la pantalla de inicio.
Crear un aviso, pulsar «Usar mi ubicación» y permitir el acceso. Revisar el punto
en Mapas, adjuntar una foto si se desea y enviar. Abrir «Simular gestión» para
cambiar el estado y volver a «Mis avisos» para comprobar el resultado.
El GPS captura coordenadas y precisión. La calle o referencia se puede añadir a mano.
